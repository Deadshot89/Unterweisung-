# Roadmap Online-System

## Phase 1 - Technische Basis

- Projektstruktur auf GitHub
- Static Web App Deployment
- Azure SQL Schema
- Startdatenimport
- Blob Storage für PDF-Vorlagen
- einfache API für Bootstrap/Mitarbeiter/Unterweisungstypen

## Phase 2 - Firmenfähigkeit

- Microsoft Entra Login
- Rollen: System Admin, Firmen Admin, HSE, Line Manager, Mitarbeiter, Extern
- companyId-Prüfung in jeder API
- Firmenverwaltung
- Audit-Log sichtbar machen

## Phase 3 - Unterweisungen online durchführen

- Einzel- und Gruppenunterweisung über API speichern
- Gültigkeit automatisch berechnen
- Nachweis-PDF erzeugen
- Nachweise hochladen und anzeigen
- Nicht-erforderlich pro Mitarbeiter/Unterweisung

## Phase 4 - Externe Links

- Einladungslink erzeugen
- Outlook/Microsoft Graph Mail senden
- Teilnehmeransicht
- Test durchführen
- Abschluss automatisch zurückschreiben

## Phase 5 - Verkaufsversion

- Manager-Reports
- Backup-/Restore-Test dokumentiert
- Datenschutzunterlagen
- Kunden-Onboarding
- Preis-/Paketlogik
