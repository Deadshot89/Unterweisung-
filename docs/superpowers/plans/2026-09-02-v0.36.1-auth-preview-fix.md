> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the signed-in Static Web Apps preview use same-origin integrated API authentication and retain the full v0.36 visual design.

**Architecture:** Deploy the existing `api` directory through the Static Web Apps workflow and point the frontend at same-origin `/api`. Move/copy the Static Web Apps configuration into the deployed `frontend` directory and add a regression check that proves the authentication wiring cannot silently regress.

**Tech Stack:** Azure Static Web Apps, Azure Functions Node.js, vanilla JS, GitHub Actions, Node assertion checks.

**Spec:** `docs/superpowers/specs/2026-09-02-v0.36.1-auth-preview-fix.md`

- Release version must be `v0.36.1`; package version `0.36.1`.
- No database schema or permission-model changes.
- No client-forged authentication headers.
- Preserve the standalone Function App deployment workflow.
- Static assets must remain loadable during login/auth redirects.
