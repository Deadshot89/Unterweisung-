# v0.36.0 Instruction Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the oversized Unterweisungen table with a compact overview/detail workspace and ship the application as v0.36.0 without changing backend behavior.

**Architecture:** Refactor the existing instruction UI directly in `frontend/instruction-type-management-v23.js`; do not add an override layer. Put v0.36-specific presentation and safe shared density rules in a new stylesheet. Keep all current API calls, permission checks, template functions and test-question functions intact.

**Tech Stack:** Vanilla JavaScript, HTML/CSS, Node.js assertion-based repository checks, Azure Static Web Apps frontend.

**Spec:** `docs/superpowers/specs/2026-09-02-v0.36-instruction-workspace-design.md`

## Global Constraints

- Visible application version must be exactly `v0.36.0`; package version must be exactly `0.36.0`.
- No database, Azure API or permission-model changes.
- No permanent `MutationObserver`, polling loop or render timer for the v0.36 workspace.
- Preserve `saveInstructionType`, `prepareInstructionTypeEdit`, `toggleInstructionType`, `templateUploadCard`, `templateListCard`, `testQuestionManagerCard` and current role checks.
- Long instruction descriptions must not control overview row height.
- Mobile/tablet content must remain reachable through wrapping or horizontal table scrolling.

**Interfaces:**

- [ ] **Step 1: Add transient workspace state and filter helper**

Add near the top of `instruction-type-management-v23.js`:

```js
const instructionWorkspaceState = {
  selectedId: '',
  search: '',
  category: '',
  status: '',
  template: '',
  questions: ''
};

function instructionQuestionCount(t){
  return (state.testQuestions || []).filter(q => q.instructionTypeId === t.id && q.active !== false).length;
}

function filteredInstructionWorkspaceRows(){
  const q = String(instructionWorkspaceState.search || '').toLowerCase().trim();
  return types().filter(t => {
    const tpl = templateForType(t);
    const questions = instructionQuestionCount(t);
    if(q && ![t.name,t.category,t.description,tpl?.title,tpl?.fileName].join(' ').toLowerCase().includes(q)) return false;
    if(instructionWorkspaceState.category && String(t.category || '') !== instructionWorkspaceState.category) return false;
    if(instructionWorkspaceState.status === 'active' && t.active === false) return false;
    if(instructionWorkspaceState.status === 'inactive' && t.active !== false) return false;
    if(instructionWorkspaceState.template === 'assigned' && !tpl) return false;
    if(instructionWorkspaceState.template === 'missing' && tpl) return false;
    if(instructionWorkspaceState.questions === 'available' && questions < 1) return false;
    if(instructionWorkspaceState.questions === 'missing' && questions > 0) return false;
    return true;
  }).sort((a,b) => String(a.category||'').localeCompare(String(b.category||''),'de') || String(a.name||'').localeCompare(String(b.name||''),'de'));
}
```
